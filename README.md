# BitBuzz Mobile

Native-feeling BitBuzz mobile client for Android first, with the same Supabase backend as the BitBuzz newsroom.

## Architecture

- Expo + React Native + TypeScript
- Expo Router
- Supabase as the shared backend
- Android application id: `app.bitbuzz.mobile`
- Existing website repository remains separate: `hridhaan-s/The-BitBuzz-Site`

The mobile app is intentionally isolated from the production website repository.
